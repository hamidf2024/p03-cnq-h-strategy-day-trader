# data/

- `raw/CNQ_5min_20200727_to_20261118.csv` — CNQ 5-minute bars, 2020-07-27 to 2026-11-18 (ET), 117,169 bars across 1,584 trading days (added 2026-11-18, Stage 9). Source: Alpaca Markets (IEX feed, free tier), **spliced** with the original Yahoo-sourced file (previously `CNQ_5min_20260520_to_20260814.csv`, now superseded and removed — its exact bars are preserved verbatim inside this file for 2026-05-20 to 2026-08-14) so every previously-published V7.1/V1-V7 result reproduces exactly from this single file (verified: n=75, win_rate_excl=72.9%, pf=3.81, net=+2.690 for V7.1 Jul1-Aug14). Outside that window, prices come from Alpaca's IEX feed.
  - **Split adjustment applied:** CNQ executed a 2-for-1 stock split effective 2024-06-11. Alpaca's raw feed is unadjusted (confirmed by an exact ~49.9% overnight price drop at that date); all bars before 2024-06-11 in this file have been divided by 2 (OHLC) / multiplied by 2 (Volume) to align with the post-split share count used everywhere else in this project.
  - **Known limitation — data-vendor sensitivity:** cross-checking the Alpaca (IEX) and Yahoo (consolidated tape) feeds over their overlap window showed prices matching closely (median diff ~0.01%, max ~0.46% on 4,679/4,680 bars) but NOT exactly tick-for-tick. Because this project's zone-touch logic uses sub-cent thresholds (e.g. V7.1's 1.2-cent `band`), even these small cross-vendor differences are large enough to flip individual zone-touch/entry decisions outside the spliced Yahoo window. Treat trade-by-trade results computed on the Alpaca-sourced portion of this file as directionally reliable (they're real exchange trade data) but not bit-for-bit reproducible from a different feed — see `06_Lessons_Learned.docx`, Stage 9, for the full discussion.
